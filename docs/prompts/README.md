# 提示词包 · 让外部大模型帮你生产可导入的材料数据

> 本应用**不接入任何大模型**（单机、离线、数据不外流）。
> 但你可以把材料交给外部大模型去整理，再用这里的提示词与工具，把它们变成**能一键导入的规范数据**。

---

## 1. 三步走

```
① 复制提示词  →  ② 让大模型产出 JSON  →  ③ 用工具转成材料包并导入
```

### ③ 把大模型产出转成材料包

**方式 A：用打包好的工具（推荐给最终用户，无需装 Python）**

```
release\MatSelectPackTool.exe
```

把大模型输出的 JSON 文件**直接拖到该 exe 上**即可（或命令行 `MatSelectPackTool.exe 你的文件.json`）。
它会：校验字段与字典 → 自动补 `uid` → 归一化同义词 → 计算校验和 → 生成 `xxx_pack.json`。

**方式 B：用源码脚本（开发者）**

```powershell
cd D:\Documents\MyDoc\CODE\MatSelect
& "C:\Users\73937\.workbuddy\binaries\python\envs\matselect\Scripts\python.exe" `
    tools\make_pack.py 你的文件.json -o 材料包.json
```

### ④ 导入应用

打开应用 →「数据分享」页 → 右栏「导入材料包」→ 拖入生成的 `xxx_pack.json`。

> **为什么必须过一遍工具**：应用导入时会校验**校验和**，而大模型算不出可靠的 sha256，
> 自行编造的校验和会被直接拒绝。工具用的是与后端**完全相同**的算法，保证一次通过。

### 退出码 / 结果含义

| 输出 | 含义 | 该怎么做 |
| --- | --- | --- |
| `[ERROR]` | 致命问题（如缺 `name`、分类不在字典、`min > max`、`limit != max`） | **不生成材料包**。按提示改数据后重跑 |
| `[WARN]` | 可继续导入的提醒（如特性词不在规范表、别名不足 2 个、已自动归一某词） | 可直接导入，但建议逐条确认 |
| `[OK]` | 校验通过并生成材料包 | 去应用里导入 |

## 3. 为什么「字典对齐」这么重要（不是格式洁癖）

本库有两条链路直接依赖术语一致性：

1. **检索召回**：用户输入「PP」要能命中 `PP`、`PP-TD20`、`PP-GF30`；
   输入「保险丝座」要能命中数据里写着 `熔断器底座` 的材料。**写法不统一 = 搜不到。**
2. **推荐打分**：推荐引擎把用户需求里的零件类型/工艺/特性词，与材料数据中的
   `applications` / `features` / `aliases` 做术语匹配。
   **数据里用同义词 → 术语命中为 0 → 该材料拿不到分、排不上来。**

举个实测例子：样例里的 `熔断器底座` 若不归一成 `保险丝座`，
用户搜「保险丝座」时这条材料就会被漏掉。

## 4. 常用字段速查

完整规格见 [`01-生成新材料.md`](./01-生成新材料.md) 第二节。最容易写错的几条：

| 规则 | 说明 |
| --- | --- |
| `service_temp_limit` **必须等于** `service_temp_max` | 前者是推荐算法的**硬约束**字段（需求温度 > 它 → 直接过滤）；两者不一致会导致推荐与详情页自相矛盾 |
| 区间一律 `_min` / `_max` 成对，且 `min ≤ max` | 数值**不带单位**，单位由字段决定 |
| `category_path` 必须是 **2 元素数组** | 如 `["热塑性塑料","工程塑料"]`，取值必须是字典原词 |
| `molding_process` 必须是字典原词 | 如 `注塑`，不要写 `注射成型` |
| `aliases` ≥ 2 个 | 决定检索召回率，至少含中文简称 + 英文/牌号变体 |
| 不要输出 `checksum` | 工具会算；自己写的会导致导入被拒 |
| `null` 表示「无数据」，不要用 `""` | 空字符串会被视为填了内容 |

## 5. 常见疑问

**Q：同一条材料，我生成两次，为什么材料包的校验和不一样？**
正常。`uid`（材料全局唯一键）是每次生成时随机分配的，而校验和覆盖包含 `uid` 的整个材料数组。
只要材料内容本身没变，导入结果就是一致的。

**Q：同一条材料重复导入会不会变成两条？**
不会静默重复。导入预览会把它识别为**冲突**（按 `uid` 或「名称+简称」匹配），
然后由你选择：`跳过·保留本机` / `覆盖·用导入值` / `另存副本·更名后新建`。

**Q：能不能不改数据，只是校验一下能不能导入？**
可以，加 `--check` 只校验不写文件：
`MatSelectPackTool.exe 你的文件.json --check`

**Q：大模型输出的 JSON 带了 `checksum` 字段怎么办？**
工具会**自动删除**并提示（删掉是正确做法，编造的校验和会导致导入被拒）。

**Q：为什么我的材料导入后搜不到？**
多半是术语没对齐。检查三处：`aliases` 是否 ≥2 个、`applications` 是否用了标准零件词、
`features` 是否用了规范词表。用 [`02-字典对齐与检索优化.md`](./02-字典对齐与检索优化.md) 处理一遍即可。

## 6. 边界与免责

- 大模型生成的是**候选数据**，数值未必准确。导入前请核对关键参数（尤其耐温上限、阻燃等级）。
- `source` 不允许编造文献/供应商名；不确定的证书写 `null`。
- 本工具定位是**辅助选型，最终以实测验证为准**。库内的 `value_type` 语义为「典型值」，
  工程判定仍需以供应商保证值或实测数据为准。
- 生成的数据是否入库、是否对外使用，由你判断。
