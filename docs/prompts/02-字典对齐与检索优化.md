# 提示词 02 · 字典对齐与检索优化

> **用途**：你手上已经有一批材料数据（可能是以前攒的 Excel/JSON、别的模型生成的、或
> 供应商资料整理的），但**术语写法不统一**——同一个意思有五六种写法，导致检索搜不全、
> 推荐命中率低。本提示词让大模型把这批数据**对齐到本库的规范字典**，并补强检索关键词。
>
> **用法**：整段复制「—— 提示词开始 ——」到「—— 提示词结束 ——」之间的内容，
> 然后在末尾**粘贴你的材料 JSON**。

---

## —— 提示词开始 ——

你是一位**术语规范化与检索优化专家**。下面是「MatSelect 汽车材料选型知识库」的规范字典，
以及一批待处理的材料数据。你的任务：**把材料数据对齐到规范字典，并提升其可检索性**。

### 一、为什么必须对齐（理解目标，才能正确取舍）

这个库有两条关键链路依赖术语一致性：

1. **检索召回**：用户输入「PP」要能命中 `PP`、`PP-TD20`、`PP-GF30`、`mPPO`；
   输入「保险丝座」要能命中应用场景写着 `熔断器底座` 的材料。**同义写法不统一 → 搜不到。**
2. **推荐打分**：推荐引擎会把用户需求里的零件类型/工艺/特性词，与材料数据中的
   `applications` / `features` / `aliases` 做匹配（术语命中 + 语义相似度）。
   **数据里用的是同义词 → 术语命中为 0 → 该材料拿不到分、排不上来。**

所以你的目标不是「写得更好看」，而是**让机器能匹配上**。

### 五、处理规则

1. **不要改变数值**。本任务只做术语归一与文本补强，`density_min`、`service_temp_limit` 等
   全部原样保留；若发现 `service_temp_limit != service_temp_max`，**不要自行修改数值**，
   在变更报告里标记为「需人工确认」。
2. **`aliases` 必须补强到 ≥2 个**。若原数据只有 1 个或没有，请补齐以下各类（优先可查证的写法）：
   - 中文简称 / 旧称（如 `尼龙66玻纤`）
   - 英文名或英文牌号（如 `PBT-GF30`、`Polybutylene Terephthalate`）
   - 书写变体（如 `PBT+30%GF`、`PBT/GF30`）
   - 用户可能输入的俗称（如 `电木`）
3. **`applications` 里把零件名替换为标准词**，但**保留原有的场景修饰**，
   例如 `汽车空调出风口` → 可写为 `出风口`；`线束固定卡扣` → `卡扣`。
   若一个标签整体不是零件名（如 `用于电池包内部`），改写为最近的标准词（`电池壳`）。
4. **`features` 全部换成规范词**；原词若含义有价值但规范词表没有，改为最接近的规范词，
   并在变更报告里说明。
5. **`description` 保留原意**，但确保其中**自然出现**该材料的 `short_name` 与至少一个应用场景词
   （提升全文检索命中）。
6. **不确定就标注**：无法判断如何归一的项目，保留原值并写进变更报告的「需人工确认」行，
   **不要猜**。
7. **不要输出 `checksum`**（导入工具会算）。
8. JSON 语法必须合法，不要注释、不要尾随逗号。

## 附：处理完后怎么用

**第 1 步**：把大模型输出的 json 代码块存成文件，例如 `aligned.json`。

**第 2 步**：转成可导入材料包 —— **把 `aligned.json` 拖到 `release\MatSelectPackTool.exe` 上**
（开发环境：`& $PY tools\make_pack.py aligned.json -o aligned_pack.json`）。

**第 3 步**：应用「数据分享」页 → 右栏「导入材料包」→ 拖入 `aligned_pack.json`。

> **冲突策略怎么选**
> - 原数据里已有本机同 `uid` 的材料 → 选「**跳过 · 保留本机**」只补新增；
> - 想用对齐后的术语**覆盖**本机旧写法 → 选「**覆盖 · 用导入值**」；
> - 想把导入值另存一份对比 → 选「**另存副本 · 更名后新建**」。
>
> 建议先「跳过」试一次（安全、可回退），确认无误再考虑覆盖。
