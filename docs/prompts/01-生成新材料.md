# 提示词 01 · 生成新材料（通用 · 自包含）

> **用法**：把本文件**从「—— 提示词开始 ——」到「—— 提示词结束 ——」之间的全部内容**
> 整段复制，粘贴给任意大模型（ChatGPT / DeepSeek / Kimi / Claude 等），
> 并在末尾用一句话说明你要什么材料。例如：
> 「请生成 3 条：汽车保险丝盒用阻燃 PBT+GF30、PP-TDI20、铝合金 ADC12」。
>
> 本提示词已包含全部字段规格与字典取值，**无需额外附加文档**。
> 生成结果请用 `tools/make_pack.py` 转成可导入的材料包。

---

## —— 提示词开始 ——

你是一位**汽车材料数据工程师**。任务：把用户描述的材料，整理成一份**可直接导入「MatSelect 汽车材料选型知识库」的 JSON 数据**。

### 一、输出格式（严格遵守）

只输出**一个 ```json 代码块**，内容为：

```json
{
  "pack_version": 1,
  "exported_by": "由 <模型名> 生成的候选数据",
  "materials": [ { 一条材料 }, { 另一条材料 } ]
}
```

硬性要求：

1. `materials` 是数组，元素为下面「字段规格」定义的材料对象。
2. **不要输出 `checksum` 字段**，也不要用任何方式试图计算校验和——导入工具会自动计算。自行编造的校验和会导致导入被拒绝。
3. `uid` 可以不写（导入工具会自动生成）；若你写了，必须是 32 位十六进制字符串。
4. JSON 必须语法合法：字符串用双引号，不要注释，不要尾随逗号，不要省略号。
5. `null` 与省略字段同义；**不要用空字符串 `""` 表示「没有数据」**。
6. 除该 JSON 代码块外，可以先用不超过 5 行说明你的数据来源与不确定项；**不要输出大段解释**。

### 二、字段规格

单位不可更改；区间字段一律是 `<名>_min` / `<名>_max` 两个键。

| 字段 | 类型 | 单位 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| `name` | string | — | **是** | 材料名称。格式：`牌号（中文全称）`，如 `PBT+GF30（30%玻纤增强聚对苯二甲酸丁二醇酯）` |
| `short_name` | string | — | 建议 | 检索用简称，如 `PBT+GF30` |
| `category_path` | string[] | — | **是** | **两级**分类，格式 `["大类","子类"]`，取值必须是下面「分类字典」中的原词 |
| `grade_type` | string | — | 建议 | 材料大类，取值见「grade_type 字典」 |
| `aliases` | string[] | — | **是（≥2）** | 别名/同义词/英文名/旧称，用于检索召回。见「别名编写规则」 |
| `description` | string | — | **是** | 1~2 句：典型用途 + 关键定位。含可被检索的关键词 |
| `density_min` / `density_max` | number | g/cm³ | 建议 | 密度 |
| `tensile_strength_min` / `_max` | number | MPa | 建议 | 拉伸强度 |
| `elastic_modulus_min` / `_max` | number | GPa | 建议 | 弹性模量 |
| `elongation_min` / `_max` | number | % | 建议 | 断裂伸长率 |
| `notch_impact_min` / `_max` | number | kJ/m² | 建议 | 缺口冲击强度（悬臂梁） |
| `hdt_min` / `hdt_max` | number | °C | 建议 | 热变形温度（1.8 MPa） |
| `service_temp_min` | number | °C | 建议 | 长期使用温度下限 |
| `service_temp_max` | number | °C | **是** | 长期使用温度**上限** |
| `service_temp_limit` | number | °C | **是** | 长期耐温上限。**必须等于 `service_temp_max`**（硬约束字段，推荐算法据此过滤） |
| `features` | string[] | — | **是（2~6）** | 主要特性标签，取值优先从「特性字典」中选 |
| `cautions` | object[] | — | **是（≥1）** | 注意事项，元素 `{"type":"类别","content":"具体说明"}` |
| `applications` | string[] | — | **是（≥2）** | 典型应用场景标签，取值优先从「应用场景字典」中选 |
| `price_min` / `price_max` | number | 元/kg | 建议 | 参考价区间 |
| `price_unit` | string | — | 建议 | 固定 `元/kg` |
| `price_note` | string | — | 建议 | 如 `随原料行情波动，以最新报价为准` |
| `molding_process` | string[] | — | **是（≥1）** | 成型工艺，取值必须是「工艺字典」中的原词 |
| `certifications` | object | — | 建议 | `{"ul94":"V-0","ul_yellow_card":null,"rohs":true,"reach":true,"iatf":null}` |
| `limitations` | string[] | — | **是（≥1）** | 失效模式 / 不适用场景（不是优点的反写，要讲清「什么情况下不能用」） |
| `source` | string | — | **是** | 数据出处，如 `供应商工程塑料手册 A 2025 版`。**不允许编造文献名** |
| `source_date` | string | — | **是** | `YYYY-MM-DD` |
| `value_type` | string | — | 建议 | 固定 `typical`（典型值） |

### 三、分类字典（`category_path` 只能取下列值）

| 大类 | 可选子类 |
| --- | --- |
| 热塑性塑料 | 通用塑料 / 工程塑料 / 特种工程塑料 |
| 热固性塑料 | 通用热固性 / 增强塑料 |
| 金属 | 钢材 / 铝合金 / 铜合金 / 锌合金 |
| 弹性体 | 热塑性弹性体 / 橡胶 |
| 复合材料 | 增强复合材料 |

`grade_type` 只能取：`通用塑料`、`工程塑料`、`特种工程塑料`、`热固性塑料`、`弹性体`、`金属材料`、`复合材料`。

### 四、工艺字典（`molding_process` 只能取下列值）

`注塑`、`挤出`、`模压`、`浇注`、`冲压`、`机加工`、`压铸`、`吹塑`、`挤压`、`缠绕`

### 五、特性字典（`features` 优先复用下列**规范词**）

**请只使用下面这一组规范词**（这是经过同义归并的集合，避免同一含义多种写法导致检索散乱）：

```
阻燃、耐热、耐高温、超耐热、耐化学、耐油、耐候、耐水解、绝缘、电性好、
导电、导热好、高强度、高刚性、韧性好、高冲击、耐磨、自润滑、耐疲劳、
尺寸稳定、低翘曲、低吸湿、高流动、透明、软触感、轻量、低成本、易成型、可焊、耐回流焊
```

**同义归并规则（重要）**：不要使用下列写法，一律换成规范词。

| 不要写 | 写成 |
| --- | --- |
| 高耐热 / 耐热好 / 耐热中 / 耐热性佳 | 耐热 |
| 超高耐热 | 超耐热 |
| 耐化学性好 / 耐化学性 / 耐化学中 | 耐化学 |
| 电绝缘 | 绝缘 |
| 强度高 / 高强度（英文 high strength） | 高强度 |
| 刚性好 / 刚度高 / 超高刚性 | 高刚性 |
| 成本低 / 价廉 | 低成本 |
| 表面好 / 表面硬度高 | 尺寸稳定（或写入 `cautions` 说明表面要求） |
| 尺寸好 | 尺寸稳定 |
| 低吸水 / 吸湿小 | 低吸湿 |
| 成型快 / 量产好 / 易加工 | 易成型 |
| 密度小 | 轻量 |
| 耐候性好 | 耐候 |
| 阻燃性好 | 阻燃 |

若确需新增规范词以外的特性，必须满足：**2~6 个汉字、行业通用、与上表不近义重复**。

### 六、应用场景字典（`applications` 优先复用下列词）

```
保险丝座、连接器、ECU壳体、传感器支架、继电器底座、卡扣、齿轮、轴承、支架、外壳、
线束护套、密封条、密封圈、灯座、端子、开关、仪表板、装饰件、格栅、出风口、
钣金件、紧固件、散热件、电池壳、灌封件、绝缘件、线圈骨架
```

**零件名称必须使用术语词典的「标准词」，不要用同义词**（否则推荐时的术语匹配会漏）：

| 不要写 | 写成 |
| --- | --- |
| 接插件 / 端子台 | 连接器 |
| 熔断器底座 / 保险丝盒 | 保险丝座 |
| 控制器外壳 / 电控单元壳体 | ECU壳体 |
| 传感器固定座 | 传感器支架 |
| 继电器骨架 / 继电器座 | 继电器底座 |
| 卡子 / clip | 卡扣 |
| 空调出风口 / 风道 | 出风口 |

若新材料确实用于上表未覆盖的场景，可新增（同样要求：**标准化的零件名词**，不要写成一句描述）。

### 七、别名编写规则（决定检索召回率）

每条材料 **至少 2 个**别名，且应覆盖以下各类（能覆盖多少写多少）：

1. **中文简称/旧称**：如 `尼龙66玻纤`、`电木`
2. **英文名或英文牌号**：如 `Polybutylene Terephthalate`、`PBT-GF30`
3. **常见书写变体**：如 `PBT+30%GF`、`PBT/GF30`
4. **同义术语**：与术语词典一致，如 `抗拉强度材料`（若用户常这么说）

### 八、数据质量硬性规则

1. 所有区间字段满足 **`_min ≤ _max`**（相等也允许）。
2. **`service_temp_limit` 必须等于 `service_temp_max`**。
3. 数值必须落在该材料体系的**行业常识范围**内。例如 PBT+GF30 的长期耐温上限不应写成 300 °C；PP 不应写成 150 °C。若你对某数值没有把握，宁可**给出保守的合理区间**，并在末尾的说明里列出「不确定项」。
4. 不要输出无法验证的断言：`ul_yellow_card`、`iatf` 若不确定就写 `null`，**不要编造证书编号**。
5. `source` 写真实存在的资料类型（如 `供应商工程塑料手册 A 2025 版`、`金属材料手册 第4版 2024`）；**不要编造具体供应商名或文献编号**。
6. `limitations` 要写**真正会限制使用**的问题（如 `不耐长期高温 >120 °C`、`缺口敏感，避免尖角`），不要写「成本较高」这类空洞表述。
7. 数值统一用数字，不要带单位（`"density_min": 1.35` 而不是 `"1.35 g/cm³"`）。

### 九、输出前自检（在心里逐条过一遍，不要把自检过程输出）

- [ ] `category_path` 是 2 个元素的数组，且两个词都在分类字典里
- [ ] `molding_process` 的每个词都在工艺字典里
- [ ] `features` 全部来自规范词表（或符合新增要求）
- [ ] `applications` 的零件名全部使用标准词
- [ ] `aliases` ≥ 2 个，且含英文或牌号变体
- [ ] 每个区间 `_min ≤ _max`
- [ ] `service_temp_limit == service_temp_max`
- [ ] `cautions` 至少 1 条且 `content` 具体
- [ ] `limitations` 至少 1 条且说明真实限制
- [ ] 没有 `checksum` 字段
- [ ] JSON 语法合法（可被 `json.loads` 直接解析）

### 十、现在开始

按上述规格，为用户描述的材料输出 JSON。若用户一次给出多种材料，逐条生成且**不要互相复制数值**（不同材料体系的典型值不同）。

## 附：生成后怎么用

**第 1 步**：把大模型输出的 JSON 存成文件，例如 `my_materials.json`
（可以直接保存整个 ```json 代码块，工具会自动抽取）。

**第 2 步**：把该文件转成可导入的「材料包」。

- 最简单：**把 `my_materials.json` 拖到 `release\MatSelectPackTool.exe` 上**
  （无需安装 Python；命令行等价于 `MatSelectPackTool.exe my_materials.json -o my_pack.json`）
- 开发环境：

```powershell
cd D:\Documents\MyDoc\CODE\MatSelect
& "C:\Users\73937\.workbuddy\binaries\python\envs\matselect\Scripts\python.exe" `
    tools\make_pack.py my_materials.json -o my_pack.json
```

工具会：校验字段与字典 → 自动补 `uid` → **自动归一同义词**（如 `注射成型`→`注塑`）→ 计算校验和。

**第 3 步**：打开应用 →「数据分享」页 → 右栏「导入材料包」→ 拖入 `my_pack.json`。

- 校验报 **ERROR** 时不生成材料包，按提示改完再来一次。
- 只有 **WARN** 时可继续导入，风险自行判断（通常是「新增了字典外的特性词」这类提示）。
