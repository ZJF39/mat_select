## 4. 技术栈落地建议（与 PRD 1.3 对齐）

| 项 | 建议 | 说明 |
| --- | --- | --- |
| 框架 | React 18 + TypeScript + Vite | PRD 已定 React + TS |
| 组件库 | Ant Design 5 | 表格 / 表单 / 筛选器 / Modal / Slider 齐全；**必须做主题覆盖**（见 `01-设计规范` §7） |
| 样式 | CSS 变量 + Tailwind（或 AntD v5 的 cssVar 模式） | Token 一套两处复用 |
| 状态 | Zustand 或 React Query | 页面级数据用 React Query 缓存；会话流与待选用 Zustand（本地持久化到后端） |
| 图标 | 统一 1.8px 描边线性图标，尺寸 10 / 12 / 14 / 16 / 17 / 22 | 见 `03-组件库规格` §2 |
| 字体 | 中文 `Noto Sans SC`；数字/参数值 `Geist Mono` | 数字等宽对齐是材料表格可读性的关键 |
| 路由 | 上方 10 条路由 | 左侧导航是**全局一级**，不是路由切换动画区 |

**AntD 覆盖必须处理的 6 项**（否则视觉会「一半是 AntD 一半是设计稿」）：
主色、圆角（6/7/10/12）、控件高度（32/34）、字体族与字号梯度、表格行高（46）与表头底色、Modal 圆角与遮罩。

## 6. 与 PRD 的差异（必须知道的 5 条）

1. **待选清单的呈现位置**：PRD 文字描述偏「底部区域」，原型改为**会话右侧常驻面板（300px）**。原因：底部弹层会遮住推荐结果，而待选的价值恰恰是「边看推荐边收」。用户可在面板收合。
2. **原型中新增、PRD 未明确的设计元素**（均为建议，落地前请拍板）：
   - 详情页 / 编辑页的「参数类型：典型值 / 保证值」——对应 PRD 遗留问题 **Q4**，原型先按「典型值」显示。
   - 详情页右栏的「变更记录（最近 3 条）」——由 D3 数据聚合，PRD 只在页头提了「最后更新」。
   - 顶栏的「本机数据已备份 · 09-14 08:00」——对应 PRD 6 章「每日自动备份」，是可见性提示，非新功能。
   - 01 屏顶栏的「导入材料包 / 导出」快捷入口——E1 / E2 的全局入口，PRD 未规定入口位置。
   - 10 屏的「导出盲区报告」——C1 的第三种消费方式（知识盲区报告）的落地按钮。
3. **表格列数**：02 屏固定 9 列。若后续要加「供应商 / 牌号级数据」，请只放入详情页——1366 宽机器上加列会触发横向滚动。
4. **不做的**：暗色模式、登录 / 权限、移动端适配、材料对比的多选拖拽重排（保留行首拖拽调序即可）。PRD 已明确推二期或不做。
5. **筛选器形态**：PRD 写「多选 / 区间」，原型用「下拉面板」承载（点击展开 Popover），不是常驻多选列表——避免首屏被筛选项占满。

## 7. 关键尺寸速查（1366 与 1440 都要成立）

```
屏宽 1440（设计基准）        屏宽 1366（PRD 最低要求）
├ 顶栏      56               ├ 顶栏      56
├ 导航栏    68（固定）        ├ 导航栏    68（固定）
├ 列表面板 264（固定）        ├ 列表面板 264（固定，可收合）
└ 主内容    1440-68-264=1108  └ 主内容    1366-68-264=1034
   内边距 24 → 内容区 1060        内边距 24 → 内容区 986
   卡片 3 列 × 342，间距 16        卡片 3 列 × 318，间距 16（或按 minmax(320px,1fr) 自动降为 2 列）
   表格行高 46 / 表头 42          同左
```

主内容区一律用 `overflow-y: auto` **单层滚动**，不要嵌套滚动容器。

## 8. 可访问性（WCAG AA）现状说明

原型主文字与辅文字均达标（`#15171C` 白底 **17.9:1**、`#565E6B` 白底 **6.5:1**）；
但**浅灰提示文字**（`#8A93A1` / `#98A1AE` / `#AAB2BD`）在 10–11px 时仅 **3.1:1**，未达 AA 正文标准。
处理原则（详见 `01-设计规范` §6）：

- 浅灰只用于**非关键、可选读**的信息（如占位符、单位后缀、辅助说明）；
- 一旦某个浅灰文本承载**决策必需信息**（如材料来源、时间、统计数），请替换为 `#6B7482`（白底 **4.7:1**，达标）。
