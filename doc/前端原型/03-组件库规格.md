## 2. 图标规范

| 项 | 规格 |
| --- | --- |
| 风格 | 线性描边，`stroke-width: 1.8`（22px 图标可用 1.8–2），`stroke-linecap: round`，`linejoin: round`，`fill: none` |
| 视框 | 统一 `24×24` viewBox，实际渲染尺寸按用途缩放 |
| 尺寸档 | `10`（折角、关闭）、`12`/`14`（行内动作、搜索）、`16`/`17`（导航、Logo 内）、`22`（上传落区）、`26`（行内图标按钮） |
| 颜色 | 默认 `text-4`（`#7A8494`），选中态 `accent`，危险动作 `danger`；**禁止用 emoji 或字符图标**（如 ✓ ★ ⚠）代替 SVG |
| 必做图标 | 搜索、导入、导出、layers（材料库）、sparkles（推荐）、exchange（数据分享）、sliders（设置）、折角上下左右、关闭、拖拽手柄、上传、编辑、历史/时钟、更多、箭头右、警告三角、信息圆、危险圆 |

## 3. 原子组件

### 3.1 `<Chip>` 标签
| 项 | 规格 |
| --- | --- |
| 尺寸 | 高 20（默认）/ 24（回评多选）/ 26（导出范围）/ 30（导入统计）；左右内边距 7，圆角 5 |
| 默认 | 底 `bg-sunken`，文字 10/`text-3` |
| 选中 | 底 `accent-soft`，文字 `accent` + 500 字重 |
| 语义变体 | `success` / `warning` / `danger` / `info` 各自用对应 `*-soft` 底 + `*-strong` 文字（见 01-设计规范 §1.4） |
| 可关闭 | 追加 10px 关闭图标，`gap 6`；关闭按钮命中区向右外扩 4px |
| 约束 | Chip 内文案不超过 12 个汉字，超出请改用信息块 |

### 3.2 `<Button>` 按钮
| 变体 | 底 | 描边 | 文字 | 用途 |
| --- | --- | --- | --- | --- |
| `primary` | `accent` | 无 | 12/500 `#FFFFFF` | 每屏唯一主操作（`加入待选` / `确认约束并生成推荐` / `保存并生效` / `导出材料包` / `确认导入` / `发送`） |
| `secondary` | `surface` | `border-control` | 12/500 `text-2` | 次级操作（`编辑材料` / `存为草稿` / `标记采用` / `取消`） |
| `ghost` | 透明 | 无 | 12/500 `accent` | 弱操作（`查看变更历史` / `重命名` / `暂不评价` / `导出对比表`） |
| `danger` | `surface` | `#EBC3C1` | 12/500 `danger` | 破坏性操作，仅 `清空我的反馈` |

- 尺寸：默认 h32 左右内边距 15；小号 h30（顶栏）；行内图标按钮 `26×26` 圆角 6。
- **状态**（原型只画了默认态，以下为实现规范）：
  | 状态 | 表现 |
  | --- | --- |
  | hover | `primary` 底 → `accent-hover`；`secondary`/`danger` 底 → `bg-subtle`；`ghost` 底 → `accent-soft` |
  | active | 整体 `translateY(0.5px)`，不加投影 |
  | focus-visible | `outline: 2px solid accent; outline-offset: 2px` |
  | disabled | `opacity: .45`，`cursor: not-allowed`，不可聚焦 |
  | loading | 文字左侧 12px 旋转指示器，宽度不跳变（保留原宽） |
- 禁止：按钮内用 emoji 当图标；同一行出现两个同权重主按钮。

### 3.3 `<Notice tone>` 提示条
| 项 | 规格 |
| --- | --- |
| 结构 | 圆角 8，内边距 10，`display:flex; gap:8; align-items:flex-start`；左侧 14×14 图标，右侧文字 12 行高 17 `fill` |
| tone | `warning` 底 `warning-soft` / 文字 `warning-strong` / 三角图标<br>`info` 底 `info-soft` / 文字 `info-text` / 信息圆图标<br>`danger` 底 `danger-soft` / 文字 `danger-strong` / 危险圆图标 |
| 用法约束 | 每屏不超过 3 条；不使用「关闭」按钮（常驻信息），除非是可忽略的一次性提示 |

## 4. 导航组件

### 4.1 `<AppNavRail>`
- 尺寸 `68 × fill`；4 个 `60×52` 项；顶部组与底部版本号 `space-between`。
- props：`items: {key, icon, label}[]`、`activeKey`、`bottomSlot`。
- 状态：默认 / hover（底 `bg-subtle`）/ 选中（底 `accent-soft` + `accent` 文字与图标）。
- 约束：**不承载二级导航**；一级项固定 4 个，新增能力请并入「设置」。

### 4.2 `<TreeRow>`
- 尺寸 `fill × 30`，圆角 6，内边距左 10（二级 26 / 三级材料 44）。
- 结构：折角图标 10 + 名称（12，`fill`）+ 计数（10 `Mono`，右）。
- props：`level`、`expandable`、`expanded`、`label`、`count`、`selected`、`onToggle`。
- 状态：默认（透明）/ hover（`bg-subtle`）/ 选中（`accent-soft` + `accent` 文字）/ 展开（折角向下，收起向右，叶子节点不显示折角）。
- 键盘：`↑/↓` 移动、`→` 展开、`←` 收起、`Enter` 选中。

### 4.3 `<TaskListItem>`
- 尺寸 `232 × 52`（面板内 `fill`），圆角 8，内边距 10，竖排间距 4。
- 结构：标题 12/500/`text-2` + 元信息 10/`text-5`（`3 条推荐 · 2 待选 · 刚刚`）。
- 状态：默认透明；hover `bg-subtle`；选中 `accent-soft` 且标题转 `accent`。
- 分组：`置顶` / 按时间（今天 / 更早），分组标签 10/`text-7`；文末「已归档任务（n）→」。

## 5. 数据展示组件

### 5.1 `<MaterialCard>`（01 屏核心）
- `342 × 180`，圆角 12，白底，描边 `border`，内边距 14，竖排间距 10，主副轴 `space-between`。
- 结构（自上而下）：`材料名 15/600 + 类别 Chip` / `全称与别名 11/text-5 单行省略` / `三列指标` / `特性 Chip 行` / `脚注（推荐工艺 + 查看详情）`。
- 指标列：`label 10/text-6 上` + `value 14 Mono 500/text-1 下`，列间 1×30 分隔线 `border-divider`，三列等宽居中。
- props：`material`（见 04-字段与接口映射 §2.1）、`onOpen`。
- 状态：默认 / hover（描边 → `accent-soft-border`）/ 缺数据（值显示 `—`，颜色 `text-7`）。
- **禁止**：卡片内放图片缩略图（材料无稳定视觉资产，会拉低一致性与加载性能）。

### 5.2 `<MaterialTableRow>`（02 屏）
- `fill × 46`，内边距左右 12，单元格均为 `fill` 宽并按列宽固定（列宽见 02-页面规格 §02）。
- 单元格结构：`Cell(frame) → 文本`；名称列 12/500/`text-1`，数值列 12 `Mono`，日期 11 `Mono`/`text-5`。
- 末列为动作组（`编辑` / `历史` / `更多`，各 26×26），右对齐。
- 状态：默认 / hover 行底 `bg-subtle` / 选中行底 `accent-soft` / 已归档行整体 `opacity .55`。

### 5.3 `<CompareRow>`（05 屏）
- `fill × 52`；列：材料 180 / 匹配度 76 / 密度 80 / 拉伸强度 110 / 耐温上限 96 / 参考价 104 / 标记 100 / 备注 290。
- 备注列可编辑：单击进入 `textarea`，失焦保存，`aria-live` 播报「已保存」。

### 5.4 `<DiffRow>`（08 屏）
- `fill × 52`；四段：字段名 190 / 变更前 `fill` / 箭头 36 / 变更后 `fill` / 类型徽章 84（右对齐）。
- 色块：高 34 圆角 6 内边距 10，文字 11 行高 15。
- props：`field`、`before`、`after`、`type: 'add' | 'remove' | 'modify'`；`type` 决定三处配色（见 02-页面规格 §08）。
- 数组类型字段用 Chip 列表渲染，新增绿底、删除红底加删除线。

### 5.5 `<ParamRow>`
- `fill × 28`，主副轴 `space-between`：label 12/`text-3` 左；value 12 `Mono` 500/`text-1` 右。
- 变体：`emphasis`（label 与 value 同时转 `accent`，用于「长期使用温度上限」）。
- 缺值：value 显示 `—` 且颜色 `text-7`。

### 5.6 `<ShortlistItem>`（04 屏右栏）
- `268 × hug`，圆角 10，白底描边 `border`，内边距 12，竖排间距 8。
- 结构：`手柄 12×14 + 材料名 12/600 + 匹配度 11 Mono/accent` / `参数摘要 10/text-5` / `标记 Chip + 移出待选 10/text-5` / `备注块（底 bg-subtle 圆角 6 内边距 8，11/text-3）`。
- 状态：默认 / hover（描边 → `accent-soft-border`，显示「移出待选」）/ 拖拽中（`opacity .6` + 跟随光标）/ 刚加入（600ms 高亮底 `accent-soft` 渐隐）。

## 6. 表单组件

### 6.1 `<FilterSelect>`（01/02 屏）
- `hug × 32`，圆角 7，白底描边 `border-control`，内边距左右 11，`gap 6`：文案 12/`text-2` + 10px 折角图标。
- 变体：默认（`分类：全部`）/ 已选（文案显示具体值且文字转 `accent`，如 `工艺：注塑`）/ 区间（`耐温上限：≥150`）。
- 点击展开 Popover：面板宽 240–320，内边距 12；多选用 Checkbox 组；区间用两个数字输入 + 10px 说明；底部 `重置` / `应用`（`应用` 为次要按钮）。**注意：条件互不阻塞，无需「查询」按钮也应即时生效**。

### 6.2 `<Field>`（07 屏）
- 竖排间距 6：label 11/500/`text-3`（必填后加 `*`，用 `accent`）+ 输入框（h34 圆角 7 白底描边 `border-control` 内边距 10，值 12/`text-1`）。
- 变体：`text` / `number` / `range`（两个数字输入 + `–`）/ `select` / `textarea` / `tag-input`（Chip + 输入框）。
- 状态：默认 / focus（描边转 `accent` + 3px `rgba(31,95,208,.12)` 外环）/ error（描边 `danger` + 下方 10px 错误文案）/ disabled（底 `bg-subtle`，文字 `text-5`）/ readonly。
- 错误文案位置固定在输入框下方 6px，且**不改变行高外的布局**（预留空间，避免跳版）。

### 6.3 `<WeightSlider>`
- 竖排间距 8：上行 `space-between`（label 11/500/`text-2` + 值 11 `Mono`/`accent`）+ 轨道 h8 圆角 4（底 `border-track`，已填充 `accent`，旋钮 14 白圆 + 2px `accent` 描边）。
- props：`label`、`hint`、`value`（0–100）、`onChange`。
- 键盘：`←/→` 步进 1，`Shift + ←/→` 步进 5，`Home/End` 到边界；`aria-valuenow` 必须是数字。

## 7. 组件复用与禁止事项

**必须复用**：颜色、字号、间距、圆角全部走 Token；按钮、Chip、提示条、参数行、树行、任务项必须是同一个组件实例。

**明确禁止**：
1. 为某一屏单独「复制一份改一改」的组件（会导致第二套视觉语言）。
2. 用 emoji / Unicode 字符（`✓` `★` `⚠` `→`）代替 SVG 图标或当作按钮后缀。
3. 在卡片内叠加投影制造层次（本设计用描边分层）。
4. 同一屏出现两个主按钮；或把「删除 / 清空」做成主按钮样式。
5. 用颜色单独承载信息（如「待验证」只用黄色不加文字）——色盲不可用，必须文字 + 颜色双编码。
