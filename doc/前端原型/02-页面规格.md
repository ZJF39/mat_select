# 02 · 页面规格（10 屏逐屏）

> 基准画布 **1440 × 900**。所有尺寸单位为 px。区域横向尺寸标 `固定值`，纵向标 `hug`（内容撑开）或 `fill`（撑满剩余）。
> 颜色 / 字号 / 圆角一律引用 `01-设计规范` 的 Token 名。

### 0.2 导航栏（组件 `NavRail`）
- w68 · bg surface · 上下内边距 10 · 上下分组 `space-between`。
- 导航项 `60×52` 圆角 9，竖排：图标 17 + 文案 10。

  - 选中：底 `accent-soft`，图标与文案换 `accent`（原型用「灰色图标 + 蓝色图标」双图层切换实现，代码里用 `currentColor` 一个图标即可）。
- 共 4 项：`材料库` / `智能推荐` / `数据分享` / `设置`；底部一行版本号 9/`text-8`。
- **实现提示**：这是一级导航，切换**不销毁**主区状态（尤其 04 屏的会话滚动位置）。

### 0.3 列表面板（两种形态）
| 形态 | 用于 | 结构 |
| --- | --- | --- |
| 分类树面板 | 01 / 02 / 03 / 07 / 08 | 面板头（标题 15/600 + 副标 10）+ 树（行 h30 圆角 6）+ 底部「管理分类体系 →」 |
| 任务列表面板 | 04 / 05 | 面板头（标题 + 计数 + `新建选型任务` 主按钮 `fill`）+ 分组标签（10/`text-7`）+ 任务项（h52 圆角 8）+ 「已归档任务（n）→」+ 底部个人数据说明（10/`text-7`） |

树的行缩进：一级 `padding-left 10`，二级 `26`，三级（材料名）`44`；可展开节点保留 10×10 折角图标。

### 0.4 主内容区
- `padding 24`、子块间距 `18`、`overflow-y auto`（**全站唯一滚动层**）。
- 页头统一：左（标题 20/600 + 副标 11/`text-5`，行距 3）｜右（动作区 gap 8–10）。
- 主标题旁边不放图标；副标写「数量 + 时间 + 口径」。

### 0.5 响应式规则
| 断点 | 行为 |
| --- | --- |
| ≥ 1440 | 设计基准，卡片 3 列 |
| 1280 – 1439 | 面板保持 264，卡片自动降为 2 列（`repeat(auto-fill, minmax(320px, 1fr))`） |
| 1024 – 1279 | 列表面板可收合（默认收起），导航栏保持 68 |
| < 1024 | **不承诺支持**（PRD 明确不做移动端），仅保证 1366×768 起可用 |

**交互**
- 整卡可点（`role="link"`，进入 03 屏）；「查看详情」与整卡同目标，不做双事件。
- 卡片 hover：描边换 `accent-soft-border`，**不加阴影、不上浮**（保持工具感）。
- 筛选项点击 → Popover 面板（多选项用 Checkbox 组，区间用两个数字输入 + `Slider`）；条件变化即刷新，无需「查询」按钮。
- 排序切换：`类别·名称`（默认）/ `密度↑` / `耐温上限↓` / `参考价↑`。
- 卡片视图 ↔ 表格视图切换写入 URL query（`?view=table`），保证可分享、可后退。

**状态**
| 态 | 表现 |
| --- | --- |
| 首次加载 | 6 张卡片骨架屏（保留卡片外框，内部置灰条），禁用筛选交互 |

| 错误 | 区块内联错误条（危险提示条）+「重试」按钮，不清空筛选 |

**交互**
- 追问：同一任务内继续输入，系统结合上下文重新解析 → **刷新而不是追加**推荐卡片（原型以「已有结果 + 新一条 assistant 消息」表达，实现时建议：新消息里给「已按成本敏感重新加权」+ 更新后的列表）。
- `+ 添加约束` → 轻量表单（零件类型 / 工艺 / 温度下拉），确认后加入标签行。
- 约束标签点 `×` 删除；点击标签文字进入编辑（只改值，不新增）。
- `加入待选` 后：卡片按钮变「已在待选 ✓」（禁用态），右侧面板新增一项并高亮 600ms。
- 待选项拖拽：按住行首手柄，键盘也可操作（`↑/↓` + `Space` 提起/放下，需有 `aria-live` 播报顺序变化）。
- 归档：确认弹窗「归档后不在默认列表显示，可在『已归档任务』检索到」。
- 任务自动建名：取首条输入前 12 字，创建后可重命名。

**状态**
| 态 | 表现 |
| --- | --- |
| 推荐中 | 消息流插入一条「解析中」占位（骨架条 + 「正在解析约束…」），禁用输入发送 |
| 无结果 | **不返回空列表**。显示信息优化提示条：「没有同时满足『温度 ≤150 °C + 注塑』的材料」+ 两个动作：`放宽温度到 140 °C 再试`（次）/ `修改约束`（主） |
