# 04 · 字段与接口映射

> 字段名与《产品需求设计书 v0.2》§4.1 / §4.2 的 SQL 结构一一对应。
> 前端类型定义以 `uid` 作为跨机器唯一标识（自增 `id` 只在本机使用，**不要**写进 URL 或导出包）。

---

## 1. 约定

| 项 | 约定 |
| --- | --- |
| 主键 | 材料对外一律用 `uid`（UUID 字符串）；任务 / 待选 / 回评用本机 `id` |
| 区间字段 | 一律 `xxx_min` / `xxx_max` 两列；前端展示时拼 `min–max`，单值则只显示 `max`（如 `service_temp_limit`） |
| JSON 字段 | 库里是 `TEXT` 存 JSON，接口层**直接返回数组/对象**，前端不再 `JSON.parse` |
| 数值单位 | 单位不进值，进 label（`耐温上限 °C` + 值 `150`）；唯一例外是 `price_unit` 由后端下发 |
| 时间 | ISO 8601 字符串（`2026-09-14T14:22:00+08:00`）；列表里显示 `09-14 14:22`，详情里显示完整 |
| 空值 | 缺失一律 `null`，**不要返回空字符串**——前端用 `null` 判断显示 `—` |
| 软删除 | `archived: true` 的材料默认不返回，需显式 `includeArchived=1` |

## 2. 材料（对齐 §4.1 `material`）

### 2.1 `<MaterialCard>` / `<MaterialTableRow>` 用到的字段

| UI 位置 | 字段 | 说明 |
| --- | --- | --- |
| 卡片标题 / 表格第 1 列 | `name` | 建议存「完整名 + 简称」，卡片只显示主名 |
| 类别 Chip / 第 2 列 | `category_id` → `category.name` | 接口直接下发 `category_name` 与 `category_path`（便于面包屑） |
| 别名行 | `aliases`（数组） | 卡片显示前 2 个，详情页全量 |
| 指标 1 | `density_min` / `density_max` | 单值时 min=max 或 min=null |
| 指标 2 | `service_temp_limit` | 推荐硬约束字段，卡片与详情页都要强调 |
| 指标 3 | `price_min` / `price_max` / `price_unit` / `price_note` | 单位由材料自身领域决定（元/kg、元/件…） |
| 特性 Chip | `features`（数组） | 卡片最多 3 个，超出省略 |
| 脚注 | `molding_process`（数组） | 卡片显示第 1 个 |
| 表格列 | `certifications.ul94`、`updated_at` | 阻燃等级取自 `certifications` |

### 2.2 详情页 / 编辑页分组映射

| 详情页区块 | 编辑页分组 | 字段 |
| --- | --- | --- |
| 力学参数 | 基本信息 + 力学参数 | `density_*` `tensile_strength_*` `elastic_modulus_*` `elongation_*` `notch_impact_*` |
| 热学参数 | 热学参数 | `hdt_*` `service_temp_min` `service_temp_max` **`service_temp_limit`** |
| 主要特性与注意项 | 特性与风险 | `features[]`、`cautions[{type, content}]` |
| 典型应用场景 | 应用与成本 | `applications[]` |
| 价格与工艺 | 应用与成本 | `price_*` `price_unit` `price_note` `molding_process[]` |
| 认证与合规 | 认证与合规 | `certifications{ ul94, ul_yellow_card, rohs, reach, iatf }` |
| 失效模式 | 特性与风险 | `limitations[]` |
| 页头元信息 | 数据来源与版本 | `source` `source_date` `value_type`（`typical` / `guaranteed`，对应 PRD Q4） |
| 页头别名行 | 基本信息 | `aliases[]` `uid`（只显示后 6 位） |
| 历史反馈卡 | — | 由 `material_negative_feedback` 聚合：`{ dimension, count, active }[]` |
| 变更记录卡 | — | 由 `material_revision` 聚合最近 3 条：`{ changed_at, summary }[]` |

## 3. 建议接口清单（FastAPI 风格）

### 3.1 材料

```
GET  /api/materials
     ?q=保险丝座&category_ids=3,4&processes=注塑&temp_min=150&price_max=30
     &flame=all&features=耐油&sort=category_name|density|service_temp_limit|price
     &order=asc|desc&archived=0&page=1&page_size=20
  → { total, items: MaterialCard[] }

GET  /api/materials/{uid}          → MaterialDetail（含 features/cautions/certifications/limitations 展开）
POST /api/materials                → 新建（body = MaterialDetail 去掉 id/uid 之外的只读字段）
PUT  /api/materials/{uid}          → 保存（后端自动写 material_revision 快照，返回 new_version）
GET  /api/materials/{uid}/revisions            → 版本列表
GET  /api/materials/{uid}/revisions/{a}/diff?against={b} → DiffPayload
POST /api/materials/{uid}/revisions/{id}/restore → 回滚（生成新快照）
GET  /api/materials/{uid}/feedback             → 该材料的历史负面反馈聚合
DELETE /api/materials/{uid}/feedback           → 清空该材料的反馈（仅本机个人数据）
GET  /api/categories                           → 两级分类树（含每节点材料计数）
```

**推荐（04 屏核心）**
```
POST /api/recommend/parse
     body { text: string }            → { constraints: { part_type, process, temp_limit, extra[] }, confidence, degraded, raw_text }
POST /api/recommend/run
     body { constraints, task_id? }   → { results: Recommendation[], degraded: bool, relaxed: [] }
```
> `recommend/parse` 与 `recommend/run` **必须拆两个接口**：用户要先确认约束标签、确认后才跑硬约束过滤（对应 B1 的「结构化解析确认」）。

**任务 / 会话**
```
GET  /api/tasks?status=active|archived&q=
POST /api/tasks                          → 新建（无 body 时由首次输入创建）
PATCH /api/tasks/{id}                    → 重命名 / 置顶 / 归档
GET  /api/tasks/{id}/messages            → 会话消息数组（按时间正序）
POST /api/tasks/{id}/messages            → 追问（后端同时返回新 assistant 消息）
```

**待选清单**
```
GET    /api/tasks/{id}/shortlist
POST   /api/tasks/{id}/shortlist              body { material_uid, tag? }
PATCH  /api/shortlist/{item_id}               body { user_note?, tag? }
PUT    /api/tasks/{id}/shortlist/order        body { ids: [...] }   ← 拖拽后提交顺序
DELETE /api/shortlist/{item_id}               → 移出待选
```

**回评**
```
POST /api/tasks/{id}/feedback
     body { result: 'success'|'fail'|'skipped', reason_text?, reason_tags[]?, material_uids[]? }
  → { parsed: { materials[], dimensions[], keywords[], confidence }, penalty_applied: bool }
GET  /api/insights/gaps?range=week     → 知识盲区报告（高频缺口维度 + 建议动作）
GET  /api/settings/feedback            → 我的负面反馈列表（含 hit_count、active）
DELETE /api/settings/feedback          → 清空
```

**导出 / 导入**
```
POST /api/export   body { scope, format: 'json'|'xlsx'|'md', include_work_data, ids?[] } → 文件流 + 文件名
POST /api/import/parse  (multipart)   → ImportPreview（先校验，不写库）
POST /api/import/commit body { token, conflict_policy: 'skip'|'overwrite'|'duplicate' } → ImportResult
```

**设置 / 系统**
```
GET  /api/settings/weights              → { dims: [{key, label, weight, hint}], penalty: {threshold, max}, sum }
PUT  /api/settings/weights
GET  /api/logs?limit=50                 → 操作日志
GET  /api/search?q=&limit=8             → 顶栏全局搜索结果（材料 / 任务 / 场景标签分组）
GET  /api/backup/status                 → { last_backup_at, location }
```

## 4. TypeScript 类型定义（可直接落地）

```ts
/* ---------- 材料 ---------- */
export type ValueType = 'typical' | 'guaranteed'

export interface Categorization {
  category_id: number
  category_name: string
  category_path: string[]          // ['热塑性塑料','工程塑料']
  grade_type?: string | null
}

export interface Certification {
  ul94?: string | null             // 'V-0 @1.5mm'
  ul_yellow_card?: string | null
  rohs?: boolean | null
  reach?: boolean | null
  iatf?: string | null
}

export interface Caution { type: string; content: string }

export interface MaterialCard extends Categorization {
  uid: string
  name: string
  short_name?: string | null
  aliases: string[]
  density_min: number | null
  density_max: number | null
  service_temp_limit: number | null
  price_min: number | null
  price_max: number | null
  price_unit: string | null        // '元/kg'
  features: string[]
  molding_process: string[]
  archived?: boolean
}

export interface MaterialDetail extends MaterialCard {
  description?: string | null
  tensile_strength_min: number | null; tensile_strength_max: number | null
  elastic_modulus_min: number | null;  elastic_modulus_max: number | null
  elongation_min: number | null;       elongation_max: number | null
  notch_impact_min: number | null;     notch_impact_max: number | null
  hdt_min: number | null;              hdt_max: number | null
  service_temp_min: number | null;     service_temp_max: number | null
  cautions: Caution[]
  applications: string[]
  price_note?: string | null
  certifications: Certification
  limitations: string[]
  source?: string | null
  source_date?: string | null
  value_type: ValueType
  created_at: string
  updated_at: string
  negative_feedback?: { dimension: string; count: number; active: boolean }[]
  recent_revisions?: { changed_at: string; summary: string }[]
}

/* ---------- 推荐 ---------- */
export interface Constraints {
  part_type?: string | null        // '电气件'
  process?: string | null          // '注塑'
  temp_limit?: number | null       // 150
  extra: string[]                  // ['阻燃']
}

export interface ScoreBreakdown {
  temp: { got: number; max: number }
  semantic: { got: number; max: number }
  cost: { got: number; max: number }
  mechanics: { got: number; max: number }
  process: { got: number; max: number }
  feedback_penalty: number         // 0 或负值；>0 时 UI 标注「因历史反馈降分」
}

export interface Recommendation {
  material: MaterialCard
  score: number                    // 0–100，已在后端扣完 penalty
  breakdown: ScoreBreakdown
  reason: string                   // 模板生成，禁止前端拼装
  key_params: string[]             // 已格式化的关键参数行，顺序由后端保证
  cautions: string[]
  alternatives: { name: string; score: number; tradeoff: string }[]
}

export interface ParseResult {
  constraints: Constraints
  confidence: number
  degraded: boolean                // true = 未抽取到有效硬约束
  raw_text: string
}

/* ---------- 任务 / 会话 ---------- */
export type MessageRole = 'user' | 'assistant'

export interface TaskMessage {
  id: number
  role: MessageRole
  created_at: string
  text?: string                    // role = user
  constraints?: Constraints        // role = assistant
  confidence?: number
  degraded?: boolean
  results?: Recommendation[]
  relax_note?: string              // 降级提示，如「已放宽温度至 140 °C」
  reweight_note?: string           // 追问后的重加权说明
}

export interface SelectionTask {
  id: number
  title: string
  pinned: boolean
  status: 'active' | 'archived'
  created_at: string
  updated_at: string
  recommendation_count: number
  shortlist_count: number
}

/* ---------- 待选 / 回评 ---------- */
export type ShortlistTag = 'key' | 'pending' | 'rejected'

export interface ShortlistItem {
  id: number
  material: MaterialCard
  score: number
  user_note: string
  tag: ShortlistTag
  sort_order: number
  added_at: string
}

export type FeedbackResult = 'success' | 'fail' | 'skipped'

export interface FeedbackPayload {
  result: FeedbackResult
  reason_text?: string
  reason_tags?: string[]
  material_uids?: string[]
}

/* ---------- 导出包（E1/E2 交换格式） ---------- */
export interface MaterialPack {
  pack_version: 1
  exported_at: string
  exported_by: string
  material_count: number
  checksum: string
  materials: MaterialDetail[]
  work_data?: {                    // 仅当 include_work_data = true
    tasks: SelectionTask[]
    messages: TaskMessage[]
    shortlist: ShortlistItem[]
    feedback: FeedbackPayload[]
  }
}

export interface ImportPreview {
  token: string
  pack_version: number
  exported_by: string
  exported_at: string
  checksum_ok: boolean
  added: number
  updated: number
  conflicted: number
  invalid: number
  details: { uid: string; name: string; kind: 'add'|'update'|'conflict'|'invalid'; reason?: string }[]
}
```

## 5. 前端必须自己算的展示逻辑（不要塞给后端）

| 展示 | 规则 |
| --- | --- |
| 区间显示 | `formatRange(min, max)`：两者都有 → `a–b`；仅 max → `≤ b`（温度类）或 `b`（价格类按上下文）；两者都无 → `—` |
| 单位 | 从字段 label 取，例：`耐温上限 °C`；仅价格用 `price_unit` |
| 时间 | `< 1 天` → `刚刚 / n 小时前`；`< 7 天` → `昨天 / 周三`；否则 `MM-DD` |
| 匹配度 | 徽章文案固定 `匹配度 {score}%`；`score < 60` 不进入列表（后端已过滤） |
| 材料名截断 | 卡片标题超过 12 个字符时保留全部 + 允许 2 行；别名行单行省略 |
| 待选标记文案 | `key → 重点考虑`、`pending → 待验证`、`rejected → 已淘汰` |
| 权限 | 无（单机单人），不要写 `canEdit` 之类的条件渲染分支 |
